# movies-series-sql-analysis
SQL analysis of Netflix movies and TV shows
Learning project analyzing the Netflix titles dataset with SQL.

## Tools
- SQLite, DB Browser for SQLite

## Files
- 01_explore.sql: SELECT, WHERE, ORDER BY, LIKE
- 02_summarize.sql: COUNT, GROUP BY
- 03_cleaning.sql: UPDATE, COALESCE, HAVING
